# 3 курс

В этом разделе находятся материалы первого семестра по двум дисциплинам:

- [Интернет-технологии](internet-technologies/)
- [Компьютерная графика](computer-graphics/)

Материалы построены так, чтобы вы не просто получали готовый результат, а понимали, как он устроен и почему работает.

## Как будем работать

Для обеих дисциплин используется один простой набор средств:

- браузер;
- HTML;
- CSS;
- JavaScript;
- GitHub;
- Canvas для компьютерной графики.

Тяжёлые среды разработки и дополнительные программы на первых занятиях не нужны.

## Ваш репозиторий

В начале семестра создайте на GitHub **один личный репозиторий** для обеих дисциплин.

Рекомендуемое имя:

```text
third-course-имя-фамилия
```

Внутри создайте две папки:

```text
internet-technologies/
computer-graphics/
```

Для каждого занятия создавайте отдельную папку:

```text
internet-technologies/
  01/
  02/

computer-graphics/
  01/
  02/
```

В папке работы должны находиться исходный код и короткий `README.md`, если в задании требуется пояснение.

## Как создать репозиторий на GitHub

1. Войдите в GitHub.
2. Нажмите **New repository**.
3. Укажите имя репозитория, например `third-course-ivan-ivanov`.
4. Выберите **Public**, если не дано другое указание.
5. Добавьте `README.md`.
6. Создайте репозиторий.
7. Внутри создайте папки `internet-technologies` и `computer-graphics`.

Работать можно через обычный редактор GitHub или через `github.dev`: на странице репозитория нажмите клавишу `.`.

## Использование AI

AI можно использовать как инструмент: для объяснения непонятной части, поиска ошибки, проверки идеи или обсуждения вариантов решения.

При этом вы должны понимать код, который сдаёте, и уметь самостоятельно объяснить, как он работает и что изменится при изменении входных данных.

Готовый код без понимания задачи не считается выполненной работой.

## Общая логика семестра

Интернет-технологии дают вам средства для создания интерактивных программ в браузере. Компьютерная графика использует те же JavaScript и Canvas для изучения графических алгоритмов.

Поэтому две дисциплины постепенно будут связываться между собой: интерфейс, обработка событий, хранение данных и работа браузера будут использоваться в графических программах.
