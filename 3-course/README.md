# 3 курс

В этом разделе находятся материалы первого семестра по двум дисциплинам:

- [Интернет-технологии](internet-technologies/)
- [Компьютерная графика](computer-graphics/)

Материалы будут добавляться постепенно по мере прохождения курса.

## Как будем работать

Для обеих дисциплин используется один набор средств:

- браузер;
- HTML;
- CSS;
- JavaScript;
- GitHub;
- Canvas для компьютерной графики.

Тяжёлое дополнительное программное обеспечение для первых занятий не требуется.

## Ваш репозиторий

Создайте на GitHub **один личный репозиторий** для работ по обеим дисциплинам.

Рекомендуемое имя:

```text
third-course-имя-фамилия
```

Внутри создайте две папки:

```text
internet-technologies/
computer-graphics/
```

Для каждого занятия создавайте отдельную папку с номером работы:

```text
internet-technologies/
  01/
  02/
  03/

computer-graphics/
  01/
  02/
  03/
```

В папке работы должны находиться исходный код и `README.md`, если в задании требуется короткое пояснение.

## Использование AI

AI можно использовать для объяснения непонятного материала, поиска ошибки, проверки идеи и обсуждения вариантов решения.

При этом вы должны понимать код, который сдаёте, и уметь объяснить, как он работает.

Готовая программа без понимания решения не считается выполненной работой.
