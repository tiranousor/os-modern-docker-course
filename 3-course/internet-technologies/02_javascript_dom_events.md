# Занятие 2. JavaScript, DOM и управление состоянием

## Что вы должны понять

На втором занятии мы продолжаем работать с браузером, но теперь задача — научиться писать код так, чтобы программа не превращалась в набор случайных обработчиков кнопок.

К концу занятия вы должны понимать:

- зачем разделять данные и отображение;
- как работают функции;
- как использовать массивы и объекты;
- как получать значения из формы;
- как изменять DOM из JavaScript;
- зачем проверять входные данные;
- как искать ошибку по шагам.

---

## 1. Данные и интерфейс — не одно и то же

Пусть на странице есть список чисел.

Плохой вариант — считать HTML единственным местом, где эти числа существуют.

Лучше хранить данные отдельно:

```javascript
const numbers = [4, 8, 15];
```

А затем строить отображение на основе массива.

```javascript
function renderNumbers() {
  // очистить область вывода
  // пройти по массиву
  // вывести элементы
}
```

Если данные меняются, мы снова вызываем функцию отображения.

Идея простая:

```text
данные -> функция отображения -> интерфейс
```

Эта схема будет использоваться весь семестр.

---

## 2. Функции

Функция должна выполнять одну понятную задачу.

Например:

```javascript
function getAverage(values) {
  let sum = 0;

  for (const value of values) {
    sum += value;
  }

  return sum / values.length;
}
```

Здесь функция получает данные и возвращает результат. Она ничего не знает о кнопках или HTML.

Отдельная функция может выводить результат:

```javascript
function renderAverage(value) {
  document.querySelector('#average').textContent = value;
}
```

Такой код проще проверять и изменять.

---

## 3. Массивы

Массив используется, когда нужно хранить несколько однотипных значений.

```javascript
const values = [10, 20, 30];
```

Добавление:

```javascript
values.push(40);
```

Количество элементов:

```javascript
values.length
```

Перебор:

```javascript
for (const value of values) {
  console.log(value);
}
```

---

## 4. Объекты

Объект удобен, когда одно значение имеет несколько свойств.

```javascript
const point = {
  x: 120,
  y: 80,
  color: 'red'
};
```

Обращение к свойству:

```javascript
console.log(point.x);
```

Позже в компьютерной графике мы будем хранить таким способом точки, отрезки, вершины и параметры сцены.

---

## 5. Получение данных из формы

Пусть в HTML есть поле:

```html
<input id="number" type="number">
```

JavaScript получает строковое значение:

```javascript
const input = document.querySelector('#number');
const value = Number(input.value);
```

Важно помнить: пользователь может оставить поле пустым или ввести неподходящее значение.

Проверка:

```javascript
if (!Number.isFinite(value)) {
  // сообщить об ошибке
}
```

Программа должна корректно реагировать на неверный ввод, а не просто переставать работать.

## 6. Практическая работа: анализатор чисел

Создайте папку:

```text
internet-technologies/02/
```

Создайте приложение, в котором пользователь может добавлять числа в список.

На странице должны быть:

- поле ввода числа;
- кнопка `Добавить`;
- кнопка `Удалить последнее`;
- кнопка `Очистить`;
- список введённых чисел;
- количество чисел;
- сумма;
- среднее значение;
- минимальное и максимальное значение.

Все исходные данные должны храниться в одном массиве JavaScript.

Например:

```javascript
const values = [];
```

После изменения массива вызывайте одну общую функцию:

```javascript
function render() {
  // обновить список и все вычисляемые показатели
}
```

## 7. Обязательные функции

Разделите решение минимум на следующие части:

```javascript
function addValue(value) {}
function removeLastValue() {}
function clearValues() {}
function getStatistics(values) {}
function render() {}
```

`getStatistics()` должна получать массив и возвращать объект, например:

```javascript
{
  count: 3,
  sum: 42,
  min: 5,
  max: 25,
  average: 14
}
```

Не вычисляйте показатели в пяти разных обработчиках событий.

---

## 8. Обработка пустого массива

Подумайте, что должны показывать минимальное, максимальное и среднее значение, если массив пуст.

Программа не должна выводить случайные значения или `Infinity`.

---

## 9. Поиск ошибок

Если результат неправильный, не пытайтесь сразу переписать весь код.

Проверяйте по частям:

1. Что находится в массиве?
2. Правильно ли работает функция вычисления статистики?
3. Правильный ли результат она возвращает?
4. Правильно ли результат выводится в DOM?

Для проверки можно временно использовать:

```javascript
console.log(values);
console.log(getStatistics(values));
```

## Главное после второго занятия

Интерфейс — это отображение данных, а не сами данные.

Если состояние программы хранится отдельно, а изменение страницы выполняется через понятные функции, программу легче проверять, расширять и использовать дальше.
