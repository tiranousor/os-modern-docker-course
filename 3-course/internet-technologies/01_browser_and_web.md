# Занятие 1. Как работает веб-приложение

## Что вы должны понять

На первом занятии важно понять, что происходит между вводом адреса в браузере и появлением интерфейса на экране.

К концу занятия вы должны понимать:

- что такое клиент и сервер;
- что делает браузер;
- чем отличаются HTML, CSS и JavaScript;
- что такое DOM;
- как браузер загружает ресурсы страницы;
- как открыть инструменты разработчика и найти ошибку;
- как связать HTML-элемент с JavaScript-кодом.

---

## 1. Из чего состоит обычная веб-страница

Минимальное веб-приложение обычно состоит из трёх частей.

### HTML

HTML описывает структуру документа: заголовки, кнопки, поля ввода, блоки, изображения.

Пример:

```html
<h1>Счётчик</h1>
<button id="increase">Увеличить</button>
<p id="value">0</p>
```

Сам по себе HTML почти ничего не «делает». Он описывает, какие элементы есть на странице.

### CSS

CSS отвечает за внешний вид: размеры, отступы, расположение, цвета, шрифты.

```css
button {
  padding: 8px 16px;
}
```

### JavaScript

JavaScript отвечает за поведение.

```javascript
let value = 0;

const button = document.querySelector('#increase');
const output = document.querySelector('#value');

button.addEventListener('click', () => {
  value += 1;
  output.textContent = value;
});
```

После нажатия кнопки меняется значение переменной, а затем изменяется содержимое элемента на странице.

---

## 2. Что такое DOM

После загрузки HTML браузер строит объектное представление документа — DOM.

Условно документ

```html
<body>
  <h1>Пример</h1>
  <button>Нажать</button>
</body>
```

можно представить как дерево:

```text
body
├── h1
└── button
```

JavaScript работает не с текстом HTML-файла напрямую, а с этим деревом объектов.

Например:

```javascript
const button = document.querySelector('button');
```

находит объект кнопки.

А команда

```javascript
button.textContent = 'Готово';
```

изменяет его содержимое.

---

## 3. События

Пользователь постоянно создаёт события:

- нажимает кнопку;
- вводит текст;
- двигает мышь;
- меняет значение ползунка;
- нажимает клавишу.

JavaScript может реагировать на них.

```javascript
button.addEventListener('click', () => {
  console.log('Кнопка нажата');
});
```

Позже этот же механизм понадобится в компьютерной графике: например, по движению мыши можно будет задавать координаты точек или вращать объект.

---

## 4. Инструменты разработчика

Откройте страницу в браузере и нажмите `F12`.

Нас будут интересовать прежде всего:

- **Elements** — структура страницы;
- **Console** — сообщения JavaScript и ошибки;
- **Network** — файлы и запросы, которые загружает браузер;
- **Sources** — исходный код.

Если программа «ничего не делает», первым делом нужно открыть **Console**, а не переписывать всё заново.

Например:

```javascript
console.log(value);
```

позволяет увидеть значение переменной во время работы программы.

## 5. Первая программа

Создайте папку:

```text
internet-technologies/01/
```

В ней создайте три файла:

```text
index.html
style.css
app.js
```

### Требование

Сделайте небольшую страницу, на которой есть:

- числовое поле;
- кнопки `+1`, `-1`, `Сброс`;
- текущее значение;
- сообщение о том, является число положительным, отрицательным или равным нулю.

Нельзя хранить три разных значения в разных элементах страницы. Состояние должно храниться в одной JavaScript-переменной, а интерфейс должен отображать её текущее значение.

Пример логики:

```javascript
let value = 0;

function render() {
  // обновление интерфейса по текущему value
}
```

Каждая кнопка сначала изменяет `value`, затем вызывает `render()`.

## 6. Что нужно проверить

Проверьте программу в следующих случаях:

1. Начальное значение `0`.
2. Несколько нажатий `+1`.
3. Несколько нажатий `-1`.
4. Переход через ноль.
5. Сброс после положительного значения.
6. Сброс после отрицательного значения.

Добавьте в `README.md` короткие ответы:

- где в программе хранится состояние;
- какая функция обновляет интерфейс;
- какие события обрабатываются;
- что произойдёт, если изменить значение переменной, но не вызвать функцию обновления интерфейса.

## Главное после первого занятия

Веб-приложение — это не набор HTML-тегов. Браузер строит из документа структуру объектов, JavaScript изменяет состояние программы и по событиям пользователя изменяет интерфейс.

На следующих занятиях мы будем постепенно отделять данные программы от отображения и строить более сложные интерактивные приложения.
