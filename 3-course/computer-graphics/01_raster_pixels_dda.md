# Занятие 1. Растровая графика, пиксели и алгоритм ЦДА

## Что вы должны понять

Компьютерная графика начинается не с готовых фигур и не с вызова `line()` или `stroke()`. В основе растрового изображения находится прямоугольная сетка пикселей.

На этом занятии разберём:

- что такое растр;
- как задаётся положение пикселя;
- почему математическая линия и линия на экране — не одно и то же;
- что такое растеризация;
- как устроен простой буфер изображения;
- как работает алгоритм ЦДА;
- какие недостатки есть у ЦДА.

## 1. Что такое растровое изображение

Экран можно представить как таблицу маленьких элементов — пикселей.

Например, изображение размером `8 x 5` содержит 40 пикселей:

```text
(0,0) (1,0) (2,0) ... (7,0)
(0,1) (1,1) (2,1) ... (7,1)
...
(0,4) (1,4) (2,4) ... (7,4)
```

У каждого пикселя есть координаты и цвет.

В браузере система координат Canvas устроена так:

```text
(0,0) -----------------> x
  |
  |
  |
  v
  y
```

Точка `(0,0)` находится в левом верхнем углу. Координата `x` увеличивается вправо, `y` — вниз.

---

## 2. Математическая линия и экран

В математике отрезок между точками непрерывен. Между двумя его точками можно найти бесконечно много других точек.

Экран дискретный: пиксель либо есть, либо нет.

Поэтому возникает задача:

> какие именно пиксели нужно выбрать, чтобы они как можно лучше изображали математический отрезок?

Процесс преобразования геометрического объекта в набор пикселей называется **растеризацией**.

---

## 3. Canvas как область вывода

Создадим элемент:

```html
<canvas id="canvas" width="600" height="400"></canvas>
```

Получим контекст:

```javascript
const canvas = document.querySelector('#canvas');
const ctx = canvas.getContext('2d');
```

В обычной разработке можно написать:

```javascript
ctx.beginPath();
ctx.moveTo(10, 10);
ctx.lineTo(200, 100);
ctx.stroke();
```

Но на занятиях по компьютерной графике эта команда нам почти бесполезна: браузер сам выполнит алгоритм растеризации, а наша задача — разобраться в нём самостоятельно.

Поэтому будем строить изображение из пикселей.

---

## 4. Функция вывода пикселя

Для начала можно использовать простую функцию:

```javascript
function putPixel(x, y, color = 'black') {
  ctx.fillStyle = color;
  ctx.fillRect(Math.round(x), Math.round(y), 1, 1);
}
```

Чтобы пиксели были хорошо видны во время изучения алгоритма, удобно использовать масштаб:

```javascript
const scale = 10;

function putPixel(x, y, color = 'black') {
  ctx.fillStyle = color;
  ctx.fillRect(x * scale, y * scale, scale, scale);
}
```

Тогда один логический пиксель будет отображаться квадратом `10 x 10` пикселей экрана.

## 5. Как получить точки отрезка

Пусть есть две точки:

```text
A(x1, y1)
B(x2, y2)
```

Разность координат:

```text
dx = x2 - x1
dy = y2 - y1
```

Если отрезок длиннее по оси `x`, удобно делать примерно один шаг по `x` за итерацию. Если длиннее по `y` — примерно один шаг по `y`.

Количество шагов можно определить так:

```javascript
const steps = Math.max(Math.abs(dx), Math.abs(dy));
```

Тогда изменение координат за один шаг:

```javascript
const xStep = dx / steps;
const yStep = dy / steps;
```

---

## 6. Алгоритм ЦДА

ЦДА — цифровой дифференциальный анализатор.

Идея алгоритма очень простая:

1. Начать в первой точке.
2. Вычислить небольшое приращение `x` и `y`.
3. На каждом шаге прибавлять эти значения.
4. Округлять текущие координаты до координат пикселя.

Пример реализации:

```javascript
function lineDDA(x1, y1, x2, y2) {
  const dx = x2 - x1;
  const dy = y2 - y1;
  const steps = Math.max(Math.abs(dx), Math.abs(dy));

  if (steps === 0) {
    putPixel(x1, y1);
    return;
  }

  const xStep = dx / steps;
  const yStep = dy / steps;

  let x = x1;
  let y = y1;

  for (let i = 0; i <= steps; i += 1) {
    putPixel(Math.round(x), Math.round(y));
    x += xStep;
    y += yStep;
  }
}
```

## 7. Разберём пример вручную

Пусть нужно построить отрезок:

```text
A(2, 2)
B(8, 5)
```

Получаем:

```text
dx = 6
dy = 3
steps = 6
xStep = 1
yStep = 0.5
```

Точки до округления:

```text
(2.0, 2.0)
(3.0, 2.5)
(4.0, 3.0)
(5.0, 3.5)
(6.0, 4.0)
(7.0, 4.5)
(8.0, 5.0)
```

После округления получаем набор пикселей.

Обратите внимание: мы не рисуем «настоящую» непрерывную линию. Мы выбираем набор дискретных клеток растра.

---

## 8. Что происходит при вертикальной линии

Например:

```text
A(4, 2)
B(4, 9)
```

Тогда:

```text
dx = 0
dy = 7
steps = 7
xStep = 0
yStep = 1
```

Алгоритм продолжает работать.

То же самое должно происходить для горизонтальных линий и линий, построенных справа налево или снизу вверх.

---

## 9. Недостатки ЦДА

Алгоритм прост и хорошо показывает идею растеризации, но в нём есть недостатки:

- используются вещественные числа;
- выполняется деление;
- на каждом шаге требуется округление;
- возможно накопление погрешности.

Исторически это было особенно важно из-за стоимости операций с вещественными числами.

Следующий алгоритм — Брезенхема — позволяет принимать решение о следующем пикселе в основном с помощью целочисленных вычислений.

# Практическая работа

Создайте папку:

```text
computer-graphics/01/
```

Создайте страницу с Canvas.

## Часть 1. Сетка

Сделайте логическую область размером не менее `40 x 30` пикселей и увеличьте каждый логический пиксель на экране, чтобы результат был хорошо виден.

## Часть 2. Точка

Реализуйте функцию:

```javascript
putPixel(x, y, color)
```

## Часть 3. ЦДА

Реализуйте самостоятельно:

```javascript
lineDDA(x1, y1, x2, y2)
```

Не используйте `ctx.lineTo()` для построения отрезка.

## Часть 4. Управление

Добавьте четыре поля для координат начала и конца отрезка и кнопку `Построить`.

После нажатия Canvas должен очищаться и строиться новый отрезок.

## Часть 5. Проверка

Проверьте минимум следующие случаи:

```text
(2, 2) -> (20, 8)
(20, 8) -> (2, 2)
(5, 2) -> (5, 20)
(2, 10) -> (25, 10)
(3, 20) -> (12, 2)
(8, 8) -> (8, 8)
```

## Часть 6. Таблица шагов

Для одного выбранного отрезка выведите под Canvas таблицу:

```text
шаг | x до округления | y до округления | пиксель x | пиксель y
```

Это нужно для того, чтобы было видно не только готовую линию, но и ход алгоритма.

## Главное после занятия

Экран состоит из дискретных пикселей. Чтобы изобразить математический объект, нужно определить, какие элементы растра ему соответствуют.

ЦДА решает эту задачу для отрезка с помощью последовательного прибавления небольших приращений координат. На следующем занятии мы посмотрим, как ту же задачу можно решить без постоянных вещественных вычислений.
