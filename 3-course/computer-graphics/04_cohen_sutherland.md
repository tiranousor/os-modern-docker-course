# Занятие 4. Отсечение отрезков алгоритмом Коэна–Сазерленда

## Что вы должны понять

До этого мы решали задачи растеризации:

- строили отрезок по пикселям;
- строили окружность по пикселям.

Теперь рассмотрим другую типичную задачу компьютерной графики — **отсечение**.

Пусть на экране есть прямоугольное окно. Отрезок может:

- полностью находиться внутри;
- полностью находиться снаружи;
- частично пересекать окно.

Нужно оставить только ту часть отрезка, которая попадает внутрь прямоугольника.

К концу занятия вы должны понимать:

- что такое окно отсечения;
- как разбить плоскость на области;
- как закодировать положение точки четырьмя битами;
- зачем нужны побитовые операции `|` и `&`;
- как быстро принять или отбросить отрезок;
- как вычислить пересечение отрезка с границей окна;
- почему после изменения конца отрезка код области нужно пересчитать.

---

## 1. Окно отсечения

Пусть прямоугольник задаётся:

```text
xmin
xmax
ymin
ymax
```

В Canvas:

```text
(0,0) -----------------> x
  |
  |
  v
  y
```

Поэтому:

- слева: `x < xmin`;
- справа: `x > xmax`;
- сверху: `y < ymin`;
- снизу: `y > ymax`.

Внутри окна выполняется:

```text
xmin <= x <= xmax
ymin <= y <= ymax
```

---

## 2. Девять областей

Прямоугольник делит плоскость на девять областей:

```text
        TOP        TOP        TOP
      +------+------------+------+
 LEFT |      |            |      | RIGHT
      |      |   окно     |      |
      +------+------------+------+
        BOTTOM     BOTTOM
```

Точнее, угловые области одновременно принадлежат двум направлениям.

Например точка может быть:

```text
LEFT + TOP
```

или:

```text
RIGHT + BOTTOM
```

---

## 3. Четырёхбитный код области

Каждой точке назначим четыре бита.

Используем:

```javascript
const INSIDE = 0; // 0000
const LEFT   = 1; // 0001
const RIGHT  = 2; // 0010
const BOTTOM = 4; // 0100
const TOP    = 8; // 1000
```

Код `0000` означает: точка внутри окна.

Например:

```text
LEFT       = 0001
TOP        = 1000
LEFT + TOP = 1001
```

---

## 4. Как вычислить код точки

```javascript
function getCode(x, y, rect) {
  let code = INSIDE;

  if (x < rect.xmin) {
    code |= LEFT;
  } else if (x > rect.xmax) {
    code |= RIGHT;
  }

  if (y < rect.ymin) {
    code |= TOP;
  } else if (y > rect.ymax) {
    code |= BOTTOM;
  }

  return code;
}
```

Оператор:

```text
|
```

— побитовое ИЛИ.

Он позволяет включить нужный бит, не уничтожая остальные.

Например:

```text
0001  LEFT
1000  TOP
----
1001  LEFT + TOP
```

---

## 5. Первый быстрый случай: весь отрезок внутри

Пусть коды концов:

```text
code1 = 0000
code2 = 0000
```

Тогда обе точки внутри прямоугольника.

Можно сразу принять весь отрезок.

Условие:

```javascript
(code1 | code2) === 0
```

Почему?

Побитовое ИЛИ двух нулевых кодов:

```text
0000
0000
----
0000
```

Если хотя бы у одной точки есть внешний бит, результат уже будет не ноль.

---

## 6. Второй быстрый случай: отрезок можно сразу отбросить

Пусть:

```text
code1 = LEFT
code2 = LEFT + TOP
```

В двоичном виде:

```text
0001
1001
```

У обеих точек установлен бит `LEFT`.

Значит весь отрезок находится слева от окна и не может его пересечь.

Используем побитовое И:

```javascript
(code1 & code2) !== 0
```

Пример:

```text
0001
1001
----
0001
```

Получилось не ноль — есть общая внешняя полуплоскость.

Отрезок можно сразу отбросить.

---

## 7. Самый интересный случай

Если:

```text
(code1 | code2) !== 0
```

и одновременно:

```text
(code1 & code2) === 0
```

то по одним кодам ещё нельзя решить судьбу отрезка.

Например одна точка находится слева, а вторая внутри:

```text
A ---------|--------- B
           |
         xmin
```

Нужно найти пересечение с границей окна и заменить внешний конец отрезка.

После этого код новой точки пересчитывается.

---

## 8. Параметрическая форма отрезка

Пусть:

```text
A(x1, y1)
B(x2, y2)
```

Отрезок можно записать:

```text
x(t) = x1 + t(x2 - x1)
y(t) = y1 + t(y2 - y1)
```

где:

```text
0 <= t <= 1
```

При:

```text
t = 0
```

получаем точку `A`.

При:

```text
t = 1
```

получаем точку `B`.

Эта форма удобна для вычисления пересечений с границами прямоугольника.

---

## 9. Пересечение с вертикальной границей

Например нужно пересечь:

```text
x = xmin
```

Из:

```text
x = x1 + t(x2 - x1)
```

получаем:

```text
t = (xmin - x1) / (x2 - x1)
```

После этого:

```text
y = y1 + t(y2 - y1)
```

Аналогично для:

```text
x = xmax
```

---

## 10. Пересечение с горизонтальной границей

Для верхней границы Canvas:

```text
y = ymin
```

получаем:

```text
t = (ymin - y1) / (y2 - y1)
```

и:

```text
x = x1 + t(x2 - x1)
```

Для нижней:

```text
y = ymax
```

формула такая же с `ymax`.

---

## 11. Как выбрать границу

Берём код одной точки, которая находится снаружи:

```javascript
const codeOut = code1 !== 0 ? code1 : code2;
```

Затем проверяем установленные биты.

Например:

```javascript
if (codeOut & TOP) {
  // пересечение с y = ymin
} else if (codeOut & BOTTOM) {
  // пересечение с y = ymax
} else if (codeOut & RIGHT) {
  // пересечение с x = xmax
} else if (codeOut & LEFT) {
  // пересечение с x = xmin
}
```

Если точка одновременно находится, например, слева и сверху, достаточно обработать одну из границ.

После замены точки её код вычисляется заново, и цикл продолжится.

---

## 12. Полный алгоритм

Одна из реализаций:

```javascript
function clipLine(x1, y1, x2, y2, rect) {
  let code1 = getCode(x1, y1, rect);
  let code2 = getCode(x2, y2, rect);

  let accepted = false;

  while (true) {
    if ((code1 | code2) === 0) {
      accepted = true;
      break;
    }

    if ((code1 & code2) !== 0) {
      break;
    }

    const codeOut = code1 !== 0 ? code1 : code2;

    let x;
    let y;

    if (codeOut & TOP) {
      const t = (rect.ymin - y1) / (y2 - y1);
      x = x1 + t * (x2 - x1);
      y = rect.ymin;
    } else if (codeOut & BOTTOM) {
      const t = (rect.ymax - y1) / (y2 - y1);
      x = x1 + t * (x2 - x1);
      y = rect.ymax;
    } else if (codeOut & RIGHT) {
      const t = (rect.xmax - x1) / (x2 - x1);
      x = rect.xmax;
      y = y1 + t * (y2 - y1);
    } else {
      const t = (rect.xmin - x1) / (x2 - x1);
      x = rect.xmin;
      y = y1 + t * (y2 - y1);
    }

    if (codeOut === code1) {
      x1 = x;
      y1 = y;
      code1 = getCode(x1, y1, rect);
    } else {
      x2 = x;
      y2 = y;
      code2 = getCode(x2, y2, rect);
    }
  }

  if (!accepted) {
    return null;
  }

  return { x1, y1, x2, y2 };
}
```

---

## 13. Почему цикл обязательно пересчитывает код

Допустим точка была:

```text
LEFT + TOP
```

После пересечения с левой границей она может всё ещё оставаться выше окна.

То есть было:

```text
1001
```

а стало:

```text
1000
```

Поэтому нельзя один раз вычислить коды в начале и больше их не менять.

После каждого перемещения конца отрезка код пересчитывается.

---

## 14. Что происходит с вертикальными и горизонтальными линиями

В формулах встречается деление:

```text
x2 - x1
```

или:

```text
y2 - y1
```

Для вертикального отрезка:

```text
x2 - x1 = 0
```

Но корректный алгоритм не должен пытаться пересекать вертикальную линию с вертикальной границей в ситуации, где это деление действительно требуется: если обе точки находятся слева или справа, такой отрезок будет тривиально отброшен.

Аналогично для горизонтального отрезка.

Тем не менее входные данные нужно проверять, а промежуточные значения полезно выводить во время отладки.

## Главное после занятия

Коэн–Сазерленд использует простую идею:

```text
координаты точки
       ↓
4-битный код области
       ↓
быстрая проверка двух кодов
       ↓
ACCEPT / REJECT / пересечение
```

Побитовые операции позволяют часть отрезков обработать без вычисления точек пересечения.

Если решение по кодам невозможно, один внешний конец перемещается на границу окна, его код пересчитывается, и алгоритм повторяет проверку.
