# Занятие 3. Растеризация окружности: алгоритм средней точки

## Что вы должны понять

На прошлых занятиях мы строили отрезки:

- ЦДА — через вещественные приращения и округление;
- Брезенхем — через накопленную ошибку и выбор следующего пикселя.

Теперь ту же идею дискретного выбора применим к окружности.

К концу занятия вы должны понимать:

- почему нельзя просто «нарисовать формулу окружности» на растровом экране;
- как использовать симметрию окружности;
- почему достаточно вычислять только одну восьмую часть;
- как выбирается следующий пиксель;
- что означает решающая переменная;
- как из одной вычисленной точки получить восемь симметричных;
- чем алгоритм отличается от `ctx.arc()`.

---

## 1. Математическая окружность

Окружность с центром `(cx, cy)` и радиусом `r` описывается:

```text
(x - cx)^2 + (y - cy)^2 = r^2
```

Можно выразить `y`:

```text
y = sqrt(r^2 - x^2)
```

и перебирать `x`.

Но такой подход требует:

- квадратного корня;
- вещественных вычислений;
- округления;
- отдельного решения вопроса, какие пиксели выбирать.

Для растра можно действовать иначе.

---

## 2. Симметрия окружности

Если для окружности с центром в начале координат найдена точка:

```text
(x, y)
```

то ей соответствуют ещё семь точек:

```text
( x,  y)
( y,  x)
(-x,  y)
(-y,  x)
( x, -y)
( y, -x)
(-x, -y)
(-y, -x)
```

Поэтому достаточно вычислять только одну восьмую окружности.

Остальные точки получаются симметрией.

---

## 3. Перенос к центру окружности

Если центр находится в `(cx, cy)`, добавляем координаты центра:

```javascript
function plot8(cx, cy, x, y) {
  putPixel(cx + x, cy + y);
  putPixel(cx + y, cy + x);

  putPixel(cx - x, cy + y);
  putPixel(cx - y, cy + x);

  putPixel(cx + x, cy - y);
  putPixel(cx + y, cy - x);

  putPixel(cx - x, cy - y);
  putPixel(cx - y, cy - x);
}
```

На некоторых шагах часть этих точек может совпадать. Это нормально.

---

## 4. Какие два варианта следующего пикселя рассматриваем

Начинаем сверху:

```text
x = 0
y = r
```

и постепенно увеличиваем `x`.

Пока строится одна восьмая окружности, на каждом шаге выбираем:

1. оставить `y` тем же;
2. уменьшить `y` на 1.

Условно:

```text
E   = (x + 1, y)
SE  = (x + 1, y - 1)
```

Нужно определить, какой вариант лучше соответствует идеальной окружности.

---

## 5. Функция окружности

Используем функцию:

```text
F(x, y) = x² + y² - r²
```

Если:

```text
F(x, y) = 0
```

точка лежит точно на математической окружности.

Если значение отличается от нуля, оно показывает, с какой стороны от границы находится выбранная точка.

В алгоритме средней точки не нужно каждый раз вычислять квадратные корни.

---

## 6. Решение через среднюю точку

Между кандидатами `E` и `SE` рассматривается их граница.

Вместо точного расстояния можно отслеживать специальную решающую величину `d`.

Одна из целочисленных форм начинает с:

```javascript
let x = 0;
let y = r;
let d = 1 - r;
```

Пока:

```text
x <= y
```

строится одна восьмая окружности.

---

## 7. Алгоритм

```javascript
function circleMidpoint(cx, cy, r) {
  let x = 0;
  let y = r;
  let d = 1 - r;

  while (x <= y) {
    plot8(cx, cy, x, y);

    if (d < 0) {
      d += 2 * x + 3;
    } else {
      d += 2 * (x - y) + 5;
      y -= 1;
    }

    x += 1;
  }
}
```

Здесь используются только:

- сложение;
- вычитание;
- умножение на 2;
- сравнение;
- целочисленные координаты.

---

## 8. Что означает d

`d` — не «ошибка программы».

Это решающая величина, по которой определяется, нужно ли уже уменьшить `y`.

Если:

```text
d < 0
```

выбираем вариант, в котором `y` пока остаётся прежним.

Если:

```text
d >= 0
```

окружность уже достаточно изменила направление, поэтому уменьшаем `y`.

Это та же общая идея, которую вы видели у Брезенхема для отрезка:

```text
не вычислять точную вещественную координату
→ хранить дискретную ошибку/решающую величину
→ по ней выбирать следующий пиксель
```

---

## 9. Почему условие x <= y

Мы строим только сектор от верхней точки примерно до направления 45°.

На границе этого сектора:

```text
x = y
```

После этого следующие точки уже являются отражением тех, которые мы построили раньше.

Продолжать вычисления нет смысла.

---

## 10. Пример вручную

Пусть:

```text
r = 5
```

Начало:

```text
x = 0
y = 5
d = 1 - 5 = -4
```

Первый набор точек строится для:

```text
(0, 5)
```

Так как:

```text
d < 0
```

`y` пока не меняется.

После обновления:

```text
d = -4 + 2·0 + 3 = -1
x = 1
```

Следующая базовая точка:

```text
(1, 5)
```

На каждом шаге полезно выводить таблицу:

```text
шаг | x | y | d до шага | решение | d после шага
```

## Часть 1. Построение окружности

Реализуйте:

```javascript

```

```javascript

```

для построения самой окружности.

Вынесите построение восьми симметричных точек в отдельную функцию:

```javascript
plot8(cx, cy, x, y)
```

На странице должна быть возможность включить режим, в котором точки одного шага выделяются отдельно.

---

## Часть 3. Управление

Добавьте поля:

- `cx`;
- `cy`;
- `r`.

И кнопку:

```text
Построить
```

Также добавьте очистку Canvas.

Проверьте корректность радиуса:

- `r > 0`;
- окружность должна помещаться в логическую область или программа должна корректно сообщать о выходе за границы.

---

## Часть 4. Таблица шагов

Для каждого шага выведите:

```text
шаг | x | y | d до шага | выбранный вариант | d после шага
```

В столбце «выбранный вариант» можно выводить, например:

```text
E
SE
```

или понятное текстовое описание.

---

## Часть 5. Визуализация симметрии

Для одного шага покажите восемь точек, которые получаются из базовой точки `(x, y)`.

Можно выделить их другим цветом.

Цель — визуально показать, что алгоритм реально вычисляет только одну восьмую окружности.

---

## Часть 6. Проверка

Проверьте минимум:

```text
центр (20, 15), r = 1
центр (20, 15), r = 5
центр (20, 15), r = 10
центр (10, 10), r = 8
```

Дополнительно проверьте случай, когда окружность выходит за границы логического Canvas.

---

## Часть 7. Сравнение с вычислением по формуле

Реализуйте второй учебный способ:

```text
y = round(sqrt(r² - x²))
```

Достаточно построить с его помощью один сектор и затем использовать ту же симметрию.

Для нескольких радиусов сравните:

- набор полученных пикселей;
- количество вычисленных базовых точек;
- время серии построений через `performance.now()`.

Не делайте вывод по одному запуску.

Главная задача — увидеть разницу между:

```text
формула + sqrt + округление
```

и:

```text
решающая переменная + целочисленные обновления
```

## Главное после занятия

При растеризации окружности не обязательно вычислять каждую точную координату через квадратный корень.

Можно:

```text
вычислить одну восьмую
→ на каждом шаге выбрать один из двух соседних пикселей
→ использовать решающую величину
→ восстановить остальные точки симметрией
```

Это продолжает основную идею растровых алгоритмов: непрерывный математический объект преобразуется в последовательность дискретных решений.
