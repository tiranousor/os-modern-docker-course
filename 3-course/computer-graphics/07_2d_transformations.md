# Занятие 7. Геометрические преобразования на плоскости: матрицы, перенос, масштабирование, поворот

## О занятии

В предыдущих работах мы строили и обрабатывали геометрические объекты: отрезки, окружности и многоугольники, выполняли заливку и отсечение. До сих пор их координаты в основном оставались постоянными.

Теперь задача другая: **получить новые координаты вершин**, чтобы переместить, увеличить, уменьшить или повернуть фигуру.

Преобразования нужны в редакторах, анимации, моделировании, играх и особенно в 3D-графике. В этом занятии будем работать в 2D, чтобы затем перейти к трёхмерным преобразованиям.

Используем HTML, JavaScript и Canvas. Никаких дополнительных библиотек не требуется.

---

# 1. Фигура — это набор точек

Пусть многоугольник задан вершинами:

~~~javascript
const polygon = [
  { x: 2, y: 2 },
  { x: 6, y: 2 },
  { x: 7, y: 5 },
  { x: 3, y: 7 }
];
~~~

Если изменить координаты каждой вершины по одному правилу, получим новую фигуру.

~~~text
исходные вершины
       ↓
геометрическое преобразование
       ↓
новые вершины
       ↓
отрисовка на Canvas
~~~

Важно разделять **геометрию** и **её отображение**. Функция преобразования должна возвращать координаты, а не рисовать на экране.

---

# 2. Перенос

Перенос на вектор (tx, ty):

~~~text
x' = x + tx
y' = y + ty
~~~

Например:

~~~text
P = (2, 3)
tx = 4, ty = -1

P' = (6, 2)
~~~

Простая реализация:

~~~javascript
function translatePoint(p, tx, ty) {
  return {
    x: p.x + tx,
    y: p.y + ty
  };
}
~~~

При переносе расстояния между вершинами и форма фигуры не меняются.

---

# 3. Масштабирование

Относительно начала координат:

~~~text
x' = sx * x
y' = sy * y
~~~

Если sx = sy, масштаб равномерный. Если sx и sy различаются — фигура меняет пропорции.

Пример:

~~~text
P = (3, 2)
sx = 2, sy = 3

P' = (6, 6)
~~~

Проблема: фигура масштабируется относительно точки (0, 0). Если нужна другая неподвижная точка, сначала придётся переместить систему координат.

Отрицательный коэффициент масштаба даёт отражение; нулевой — вырождение по соответствующей оси.

---

# 4. Поворот

Пусть угол поворота равен θ.

~~~text
x' = x * cos(θ) - y * sin(θ)
y' = x * sin(θ) + y * cos(θ)
~~~

JavaScript использует радианы:

~~~javascript
const radians = degrees * Math.PI / 180;
~~~

Пример для P = (2, 1) и θ = 90°:

~~~text
cos(90°) = 0
sin(90°) = 1

x' = -1
y' =  2

P' = (-1, 2)
~~~

**В Canvas ось Y направлена вниз.** Поэтому положительный угол при таких формулах визуально поворачивает фигуру по часовой стрелке, а не против неё, как в привычной математической системе координат.

---

# 5. Почему одних формул недостаточно

Если писать отдельный код для переноса, масштаба и поворота, совместные операции быстро станут неудобными.

Для последовательных преобразований используют матрицы.

Однородные координаты позволяют записать и перенос, и остальные преобразования как умножение матрицы на вектор.

Точку (x, y) представим так:

~~~text
| x |
| y |
| 1 |
~~~

Используем матрицы 3 × 3 и **векторы-столбцы**. Это соглашение важно для порядка умножения.

---

# 6. Матрица переноса

~~~text
T(tx,ty) = | 1  0  tx |
           | 0  1  ty |
           | 0  0   1 |
~~~

Проверим умножение:

~~~text
| 1 0 tx |   | x |   | x + tx |
| 0 1 ty | * | y | = | y + ty |
| 0 0  1 |   | 1 |   |   1    |
~~~

В JavaScript:

~~~javascript
function translation(tx, ty) {
  return [
    [1, 0, tx],
    [0, 1, ty],
    [0, 0, 1]
  ];
}
~~~

---

# 7. Матрицы масштаба и поворота

Масштаб:

~~~text
S(sx,sy) = | sx  0  0 |
           |  0 sy  0 |
           |  0  0  1 |
~~~

Поворот:

~~~text
R(θ) = | cosθ  -sinθ  0 |
       | sinθ   cosθ  0 |
       |   0      0   1 |
~~~

Реализация:

~~~javascript
function scaling(sx, sy) {
  return [
    [sx, 0, 0],
    [0, sy, 0],
    [0, 0, 1]
  ];
}

function rotation(degrees) {
  const angle = degrees * Math.PI / 180;
  const c = Math.cos(angle);
  const s = Math.sin(angle);

  return [
    [c, -s, 0],
    [s,  c, 0],
    [0,  0, 1]
  ];
}
~~~

---

# 8. Умножение матрицы на точку

Реализуем одну функцию, которая применяет любую из матриц к точке.

~~~javascript
function transformPoint(m, p) {
  return {
    x: m[0][0] * p.x + m[0][1] * p.y + m[0][2],
    y: m[1][0] * p.x + m[1][1] * p.y + m[1][2]
  };
}
~~~

Для наших аффинных матриц третья координата результата равна 1.

Чтобы преобразовать многоугольник:

~~~javascript
const transformed = polygon.map(p => transformPoint(matrix, p));
~~~

Исходный массив лучше не изменять: иначе при повторном нажатии кнопки преобразования могут случайно накапливаться.

---

# 9. Последовательные преобразования и умножение матриц

Если сначала нужно повернуть точку, а затем перенести её, записываем:

~~~text
P' = T * R * P
~~~

Это означает, что **к точке первой применяется правая матрица**, то есть R, а затем T.

Для сравнения:

~~~text
P' = T * R * P   — сначала поворот, затем перенос
P' = R * T * P   — сначала перенос, затем поворот
~~~

Результаты в общем случае различаются. Умножение матриц некоммутативно.

Пример: P = (2, 1), поворот 90° и перенос (3, 0).

**Сначала повернуть, потом перенести:**

~~~text
(2, 1) → (-1, 2) → (2, 2)
~~~

**Сначала перенести, потом повернуть:**

~~~text
(2, 1) → (5, 1) → (-1, 5)
~~~

Получились разные точки. Это один из главных экспериментов занятия.

---

# 10. Как перемножить матрицы

Для двух матриц A и B размером 3 × 3:

~~~text
C[i][j] = A[i][0] * B[0][j]
        + A[i][1] * B[1][j]
        + A[i][2] * B[2][j]
~~~

Функция:

~~~javascript
function multiplyMatrices(a, b) {
  const result = Array.from(
    { length: 3 },
    () => [0, 0, 0]
  );

  for (let i = 0; i < 3; i++) {
    for (let j = 0; j < 3; j++) {
      for (let k = 0; k < 3; k++) {
        result[i][j] += a[i][k] * b[k][j];
      }
    }
  }

  return result;
}
~~~

Для двух операций:

~~~javascript
const rotateThenMove = multiplyMatrices(
  translation(3, 0),
  rotation(90)
);
~~~

Проверьте, что transformPoint(rotateThenMove, {x: 2, y: 1}) даёт приблизительно (2, 2).

Из-за вычисления sin/cos вместо математического нуля иногда получается очень маленькое число, например 6.1e-17. Для сравнения вещественных координат используйте допуск, а не строгое равенство.

---

# 11. Поворот вокруг произвольной точки

Обычная R вращает вокруг (0, 0). Чтобы повернуть вокруг C(cx, cy):

1. перенести C в начало координат;
2. повернуть;
3. вернуть систему обратно.

Матрица:

~~~text
M = T(cx, cy) * R(θ) * T(-cx, -cy)
~~~

Например, если центр фигуры (100, 80), а угол 45°, то сначала отнимаем (100, 80), затем вращаем и снова прибавляем (100, 80).

Для масштабирования вокруг C используется аналогичная композиция:

~~~text
M = T(cx, cy) * S(sx, sy) * T(-cx, -cy)
~~~

Если масштабирование и поворот выполняются вокруг C, а затем добавляется перенос (tx, ty):

~~~text
M = T(tx, ty) * T(cx, cy) * R(θ) * S(sx, sy) * T(-cx, -cy)
~~~

В этом порядке сначала масштабируем вокруг C, затем вращаем вокруг C и после этого переносим.

---

# 12. Координаты фигуры и координаты экрана

Математические вычисления лучше выполнять в собственных координатах модели.

Отображение можно организовать отдельно:

~~~text
координаты вершин модели
       ↓
матрица преобразования
       ↓
новые координаты вершин
       ↓
преобразование в координаты Canvas
       ↓
отрисовка
~~~

Для визуализации можно использовать алгоритм Брезенхема из ЛР2 либо обычный контур Canvas. Но **запрещено подменять собственные преобразования вызовами ctx.translate(), ctx.rotate(), ctx.scale() или ctx.transform()**: тогда математику выполнит браузер, а не ваша программа.

Округляйте координаты только при переводе в целочисленный растр, а не после каждой матричной операции.

# Практическая работа №7. Редактор геометрических преобразований

Создайте папку:

~~~text
computer-graphics/07/
~~~

Разработайте интерактивную страницу, на которой можно преобразовывать многоугольник по заданным параметрам.

## Часть 1. Исходная фигура

Задайте многоугольник минимум с четырьмя вершинами. Координаты можно вводить вручную или выбирать точки щелчками мыши.

На Canvas одновременно показывайте:

- исходный контур одним цветом;
- преобразованный контур другим цветом;
- центр преобразования отдельным маркером.

## Часть 2. Матрицы

Самостоятельно реализуйте:

~~~javascript
translation(tx, ty)
scaling(sx, sy)
rotation(degrees)
multiplyMatrices(a, b)
transformPoint(matrix, point)
~~~

Преобразования должны действовать на все вершины.

## Часть 3. Управление

Добавьте поля:

- tx, ty — перенос;
- sx, sy — масштаб;
- угол поворота в градусах;
- cx, cy — центр поворота/масштаба;
- кнопку «Применить»;
- кнопку «Сброс».

Исходную фигуру сохраняйте отдельно от результата, чтобы изменение параметров не портило исходные вершины.

## Часть 4. Порядок операций

Добавьте два режима:

~~~text
A: сначала повернуть, потом перенести
B: сначала перенести, потом повернуть
~~~

Показывайте, что при одинаковых числах матрицы и конечные координаты могут быть разными.

Масштабирование вокруг заданного центра также должно работать.

## Часть 5. Таблица вершин

Выведите таблицу:

| Вершина | x исходный | y исходный | x новый | y новый |
|---|---:|---:|---:|---:|
| P0 | ... | ... | ... | ... |
| P1 | ... | ... | ... | ... |

Показывайте итоговую матрицу 3 × 3. Числа в интерфейсе можно округлять до двух-трёх знаков, но расчёт храните без такого округления.

## Часть 6. Обязательные проверки

Проверьте:

1. перенос (0, 0) оставляет фигуру без изменений;
2. масштаб (1, 1) оставляет фигуру без изменений;
3. поворот 360° возвращает исходные координаты с небольшой погрешностью;
4. поворот 90° вокруг (0, 0) правильно преобразует точку (2, 1);
5. поворот вокруг выбранной вершины оставляет **эту вершину** на месте;
6. режимы T * R и R * T дают разные результаты на примере из раздела 9;
7. отрицательный масштаб даёт отражение;
8. повторное изменение параметров пересчитывает фигуру из исходных координат, а не из результата прошлого нажатия.
