# Лабораторная работа №2. Стеганография, шифрование и статистический анализ

## 1. Цель работы

Цель работы — исследовать, как изменяется изображение при встраивании данных методом LSB, и сравнить несколько способов сокрытия информации с помощью статистических показателей.

В работе необходимо:

- реализовать обычное LSB-встраивание;
- реализовать извлечение скрытого сообщения;
- добавить шифрование сообщения перед встраиванием;
- реализовать псевдослучайный порядок выбора позиций;
- сравнить несколько вариантов встраивания;
- оценить незаметность и обнаружимость с помощью статистических характеристик.

Итоговая схема гибридной защиты:

```text
исходный текст
      ↓
шифрование
      ↓
ciphertext
      ↓
LSB-встраивание
      ↓
stego.png
```

Обратная схема:

```text
stego.png
      ↓
извлечение LSB
      ↓
ciphertext
      ↓
расшифрование
      ↓
исходный текст
```

Отдельную лабораторную №3 выполнять не требуется: её основная идея включена в эту работу.

# Часть 1. Обычный LSB

## 3. Встраивание сообщения

Реализуйте LSB-встраивание самостоятельно.

Общая схема:

1. преобразовать текст в байты;
2. преобразовать байты в биты;
3. последовательно обходить компоненты изображения;
4. заменять младший бит значением очередного бита сообщения;
5. сохранять новое PNG-изображение.

Пример:

```text
11010010
```

если необходимо встроить `1`:

```text
11010011
```

Значение компоненты изменилось только на 1.

---

## 4. Длина сообщения и вместимость

Программа должна понимать, сколько бит необходимо извлечь.

Рекомендуемый вариант:

```text
[4 байта длины][данные]
```

При использовании одного LSB каждого RGB-канала:

```text
capacity_bits = width × height × 3
```

Перед встраиванием необходимо проверить, помещаются ли данные вместе со служебной информацией.

Если сообщение слишком большое, программа должна завершиться с понятной ошибкой.

---

## 5. Извлечение

Реализуйте обратную операцию:

```text
stego.png
→ чтение LSB
→ восстановление байтов
→ восстановление текста
```

Проверьте полное совпадение исходного и извлечённого сообщения.

# Часть 2. Гибридный вариант: шифрование + LSB

## 6. Шифрование сообщения

Перед встраиванием текст необходимо зашифровать.

Разрешено использовать готовую криптографическую библиотеку.

Рекомендуется:

- получить ключ из пароля через PBKDF2 или другую стандартную KDF;
- использовать AES;
- случайно генерировать `salt`;
- случайно генерировать `IV/nonce`.

В скрытые данные необходимо включить всё, что потребуется для обратного восстановления:

```text
[длина]
[salt]
[IV/nonce]
[ciphertext]
```

Конкретный бинарный формат можно выбрать самостоятельно.

---

## 7. Псевдослучайные позиции

Третий вариант должен использовать не последовательный обход пикселей, а псевдослучайный порядок.

На основе пароля или полученного из него значения:

1. инициализировать генератор;
2. сформировать воспроизводимую последовательность позиций;
3. встроить данные в выбранные компоненты;
4. при извлечении восстановить тот же порядок.

Одна и та же позиция не должна использоваться несколько раз.

В результате необходимо получить три варианта:

1. **Plain LSB** — открытый текст, последовательные позиции;
2. **Encrypted LSB** — зашифрованный текст, последовательные позиции;
3. **Encrypted Random LSB** — зашифрованный текст, псевдослучайные позиции.

# Часть 3. Статистическое сравнение

## 8. Что сравниваем

Рассчитайте для каждого stego-изображения относительно исходного:

- **PSNR**;
- **SSIM**.

Оформите результаты таблицей:

| Вариант | PSNR | SSIM |
|---|---:|---:|
| Plain LSB | ... | ... |
| Encrypted LSB | ... | ... |
| Encrypted Random LSB | ... | ... |

Сделайте вывод, есть ли заметная разница между способами встраивания.

---

## 10. Доля изменённых компонент

Посчитайте:

```text
changed_ratio =
число изменённых компонент /
общее число компонент
```

Для каждого варианта укажите:

- количество изменённых компонент;
- долю изменённых компонент.

Это позволит сравнить визуально незаметные изменения количественно.

|---|---:|---:|
| Cover | ... | ... |
| Plain LSB | ... | ... |

Сравните распределения.

## 12. χ²-анализ

Выполните простой χ²-тест по распределению пар значений `2k` и `2k+1`.

Цель — посмотреть, меняется ли статистическая структура младших битов после встраивания.

Не требуется строить полноценный детектор или ROC-кривую.

Достаточно для каждого варианта получить:

- значение χ²;
- p-value.

Сравнение оформить таблицей:

| Вариант | χ² | p-value |
|---|---:|---:|
| Cover | ... | ... |
| Plain LSB | ... | ... |
| Encrypted LSB | ... | ... |
| Random LSB | ... | ... |

Интерпретируйте результат: какие варианты сильнее изменили статистику изображения.

---

## 13. Влияние объёма данных

Для одного изображения повторите эксперимент хотя бы для **двух уровней заполнения**, например:

- небольшой payload;
- заметно больший payload.

Можно использовать, например:

```text
1%
5%
```

или два других разумных значения.

Для этих двух уровней достаточно сравнить:

- PSNR;
- changed_ratio;
- p-value χ².

Не требуется повторять все графики.

Цель — увидеть, как увеличение объёма скрытых данных влияет на незаметность и обнаружимость.
