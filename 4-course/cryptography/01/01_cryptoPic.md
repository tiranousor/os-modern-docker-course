# Лабораторная работа №1. Шифрование изображений и статистическое сравнение методов

## 1. Цель работы

Цель работы — не только реализовать несколько способов шифрования изображения, но и **сравнить их результат с помощью статистических характеристик**.

В работе необходимо:

- реализовать собственный простой потоковый вариант шифрования на основе XOR;
- выполнить шифрование изображения с помощью AES;
- сравнить AES-ECB и один из режимов `CBC` или `CTR`;
- обеспечить корректное восстановление исходного изображения;
- сравнить результаты разных методов по нескольким численным показателям;
- сделать вывод, какие свойства исходного изображения сохраняются или исчезают после шифрования.


---

## 2. Исходные изображения

В папке лабораторной находятся:

- `gradient.png` — плавный градиент;
- `checkerboard.png` — шахматная структура;
- `noise_texture.png` — шумовая текстура.

Дополнительно необходимо взять **одно собственное PNG-изображение** размером не менее 256×256.

Для основного сравнения достаточно выбрать **два изображения разного типа**, например:

- `gradient.png`;
- `checkerboard.png` или собственное изображение.

Не требуется строить все графики для всех изображений.

# Часть 1. Реализация методов

## 3. Потоковый вариант: XOR с ключевым потоком

Реализуйте собственный простой генератор псевдослучайной последовательности, например:

- `xorshift32`;
- LCG;
- другой простой генератор после согласования.

Из ключа должно получаться начальное состояние генератора.

Для каждого байта изображения:

```text
cipher[i] = plain[i] XOR keystream[i]
```

Расшифрование выполняется тем же действием:

```text
plain[i] = cipher[i] XOR keystream[i]
```

После расшифрования исходное изображение должно быть восстановлено полностью.

---

## 4. AES

Для AES разрешено использовать готовую криптографическую библиотеку.

Необходимо выполнить шифрование:

1. **AES-ECB**;
2. **AES-CBC или AES-CTR** — один режим на выбор.

Для выбранного CBC/CTR необходимо корректно работать с `IV/nonce`.

Нужно понимать:

- `KEY` — секретный ключ;
- `IV/nonce` — не обязан быть секретным, но должен быть корректно сформирован и сохранён;
- при расшифровании используется тот же `IV/nonce`;
- повторное использование одного и того же `IV/nonce` при одном ключе может быть ошибкой в зависимости от режима.

Для параметров шифрования можно использовать `meta.json`.

Пример:

```json
{
  "algorithm": "aes-ctr",
  "nonce": "...",
  "source": "gradient.png"
}
```

Ключ в `meta.json` сохранять не нужно.

# Часть 3. Статистическое сравнение методов

## 6. Что сравниваем

Для одного выбранного изображения получите результаты:

1. исходное изображение;
2. потоковый XOR;
3. AES-ECB;
4. AES-CBC или AES-CTR.

Для этих четырёх вариантов необходимо провести одинаковый набор измерений.

---

## 7. Энтропия

Рассчитайте энтропию распределения значений пикселей или байтов.

Для дискретной случайной величины:

```text
H = - Σ p(i) · log2 p(i)
```

где `p(i)` — относительная частота значения `i`.

Сравните энтропию:

- исходного изображения;
- потокового варианта;
- AES-ECB;
- AES-CBC/CTR.

Результаты занесите в одну таблицу.

Пример структуры:

| Метод | Энтропия |
|---|---:|
| Исходное изображение | ... |
| Потоковый XOR | ... |
| AES-ECB | ... |
| AES-CTR | ... |


---

## 8. Корреляция соседних пикселей

Из изображения выберите набор соседних пикселей и рассчитайте коэффициент корреляции.

Достаточно двух направлений:

- горизонтального;
- вертикального.

Используйте коэффициент корреляции Пирсона.

Смысл измерения:

- у обычного изображения соседние пиксели часто сильно связаны;
- у хорошо перемешанного шифротекста эта связь должна уменьшаться.

Результаты оформить одной таблицей:

| Метод | Corr H | Corr V |
|---|---:|---:|
| Исходное | ... | ... |
| Потоковый XOR | ... | ... |
| AES-ECB | ... | ... |
| AES-CBC/CTR | ... | ... |

---

## 9. Гистограмма

Для того же изображения постройте гистограммы значений:

- исходного изображения;
- потокового варианта;
- AES-ECB;

Не нужно строить отдельный набор для каждого канала и каждого изображения.

Достаточно одного общего рисунка или одного набора графиков для **одного выбранного изображения**.

По гистограммам и численным метрикам сделайте общий вывод.

---

## 10. Чувствительность к изменению ключа

Для одного метода выполните дополнительный эксперимент внутри основной работы:

1. зашифруйте одно изображение ключом `K1`;
2. измените в ключе один бит или один символ и получите `K2`;
3. зашифруйте то же изображение вторым ключом;
4. сравните два результата.

Рассчитайте:

### NPCR

```text
NPCR = количество различающихся элементов / общее количество элементов × 100%
```

### UACI

```text
UACI = (1/N) · Σ |C1 - C2| / 255 · 100%
```

Достаточно выполнить этот эксперимент **для одного выбранного метода** и одного изображения.
